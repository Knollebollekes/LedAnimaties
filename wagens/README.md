# Wagens

Hier komt per carnavalswagen een map, bijvoorbeeld `2027-heksenketel/`.

In elke wagenmap staat:
- `instellingen.h` — hoe de panelen van díe wagen zijn aangesloten
- `README.md` — het thema en welke animaties waar op de wagen komen
- een map per animatie

Een nieuwe wagen beginnen? Zeg tegen Claude: *"We beginnen een nieuwe wagen"*.
Claude stelt dan eerst een paar vragen over de panelen.
