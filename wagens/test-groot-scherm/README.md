# Groot scherm (2 x 3 panelen)

Testopstelling met 6 panelen van 16 x 16: 2 naast elkaar, 3 onder elkaar
(32 x 48 ledjes). Eén datadraad op pin 14.

Volgorde van de panelen (gezien van voren):

| links | rechts |
|-------|--------|
| 2     | 1      |
| 4     | 3      |
| 6     | 5      |

Elke rij panelen begint dus rechts (`PANELEN_VAN_RECHTS true`), geen zigzag.
Binnen elk paneel komt de draad rechtsboven binnen.
