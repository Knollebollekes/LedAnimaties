# Kleding (1 paneel, powerbank)

Eén paneel van 16 x 16 in de kleding, met een ESP32 en een USB-powerbank.
Datadraad op pin 14, binnen het paneel komt de draad rechtsboven binnen.

Stroomgrens 1,5 A: een powerbank levert meestal 2 tot 3 A per poort.
Later luisteren deze schermpjes ook naar de master (ESP-NOW).

Thema: landenvlaggen met eten van dat land.
